你把需求交给它，剩下的几小时它自己跑

Claude Code、Codex 这类 AI 编程 CLI 很能干，但都要人守着：等它问话、催它继续、 上下文满了得手动收尾。WhatyTerm 把这些盯守的活接过去 —— 它读屏判断 CLI 当前在干什么， 该答就答、该催才催、上下文快满时先让它把进度写进记忆再换一个干净窗口接着做。

长程编程

v1.4 新架构

一次交待清楚，然后可以去睡觉。它不做任务拆解 —— 拆解交给 CLI 自己， 它只管一件事：让这段工作在上下文用完之后还能接着往下走。

上下文用满了会自己交接

水位到阈值时，先让它把进度、已确认的结论、失败过的方案写进项目记忆， 再开一个干净窗口从记忆接上。不是简单压缩，是真的换一段新对话。

有个监督者在旁边判断

每段结束时判断：继续、叫人、还是项目已完成。它拿不准的事不替你决定， 会停下来在面板上问你，你回一句它接着跑。

花了多少钱看得见

按模型定价实时结算，每段调用花多少、今天累计多少都在面板上。 可以设总预算，到了就停机保住现场。

收工给结论，不是丢个状态码

结束时告诉你做完了什么、改了哪些文件、下一步该干什么。 跑挂了会说清真实原因 —— 是供应商没渠道还是代码有问题，分得清。

普通会话也能随时转成长程：转之前它会先让当前 CLI 把这一段的上下文写进记忆，再交给无人值守接手。

常见问题

个人用户真的完全免费吗？

是的。产品功能全部开放，包括长程编程。代码也是公开的。个人版限 3 台设备。

它会不会自己乱按、把我的代码改坏？

自动操作默认关着，要你自己打开。打开之后也有几道闸：AI 对该不该按把握不足时只给建议不动手； CLI 在问你业务决策（比如"这两个方案选哪个"）时它不会替你答，会停下来等你； 连着催了几次没有进展就熔断，交回给你。长程编程还会每段打一个 git 快照，跑坏了能回退。

要另外给它 API Key 吗？

不用。它用你机器上 CLI 已经配好的地址和登录，你换供应商它跟着换。 监控判断也是调这些 CLI 本身，不经过我们的服务器 —— 代码和密钥不出你的机器。

长程编程一晚上会花多少钱？

取决于你用的模型和项目大小 —— 它调用的是你自己的 API，费用直接产生在你的供应商那边。 面板上按模型定价实时结算，能看到每段花了多少、今天累计多少；可以设总预算，到了就停机保住现场。

企业版多的是什么？

专属中转服务器（固定域名，远程连接更稳）、不限设备数、专属技术支持和定制开发。 功能上没有为付费另设开关。
